## 交付范围

- **本仓库提供** 各车型的 `gocsdk` 补丁产物、生成脚本、适用固件指纹和接口文档。
- **接入方负责** App 适配、车机部署、iAP2 和 CarPlay 会话，以及实车验证与后续维护。

## 车型目录约定

每个年款目录包含 `原车修改教程.md`、`DiPlay接入教程.md`、补丁生成脚本，以及 `产物/` 下的候选文件和 `SHA256SUMS`。新增车型时沿用 `车型/<品牌>/<车型>/<年款>/`。同一车型年款存在多套车机时，在年款下按厂商或固件构建继续分目录。适用范围始终以对应的原车 SHA-256 为准。
